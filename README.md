# DeepSeek - работа с API + консольный вариант приложения

## Установка

### Перед работой необходимо зарегестрироваться на [платформе](https://platform.deepseek.com/) и [создать API-ключ](https://platform.deepseek.com/api_keys). 

[Подробнее в статье](https://blog.mihailgok.ru/deepseek-api/)


### DeepSeek использует библиотеку OpenAI поэтому установим ее (+ markdown_pdf чтобы создавать pdf):

```
pip3 install openai
pip3 install markdown_pdf
```

Либо используйте сразу готовый файл связей: 

```
pip3 install -r requirements.txt
```

## Запуск: 

```
python3 main.py
```

Ответы записываются в папку `answers/` в формате MarkDown







Temperature — про характер ответа.
Он контролирует, насколько «смелым» или, наоборот, предсказуемым будет ответ модели.

Диапазон: От 0.0 до 2.0.
Это позволяет тонко настраивать баланс между точностью и креативностью.

Значение по умолчанию: 1.0.

Как работает:
Низкие значения (0.0 – 0.3):
Ответ максимально предсказуем и точен.
Модель из раза в раз будет выбирать самый вероятный вариант ответа.
Идеально для: кода, фактов, документации.

Средние значения (0.5 – 0.8):
Модель начинает немного «фантазировать», но остаётся в рамках приличий.
Идеально для: обычных диалогов, пересказов, бизнес-писем.

Высокие значения (1.0 – 1.5):
Максимальная креативность и случайность.
Ответы могут быть неожиданными, образными, но иногда бессмысленными.
Идеально для: генерации идей, творчества, игр.

Как это выбрать?
Если нужна точность — ставьте ниже (0.2–0.4).
Если нужна креативность и разнообразие — выше (0.7–1.0).
Для чистого кода можно смело ставить 0.0.
