Вот простая и эффективная функция для вычисления факториала (итеративная версия):

```python
def factorial(n: int) -> int:
    """
    Вычисляет факториал целого неотрицательного числа n.

    Args:
        n (int): неотрицательное целое число.

    Returns:
        int: значение n! (факториал).

    Raises:
        ValueError: если n отрицательное.
        TypeError: если n не является целым числом.
    """
    if not isinstance(n, int):
        raise TypeError("n должно быть целым числом")
    if n < 0:
        raise ValueError("Факториал определён только для неотрицательных чисел")
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result
```

При необходимости можно использовать рекурсивный вариант, но итеративный более производительный и не подвержен ошибкам переполнения стека при больших n:

```python
def factorial_recursive(n: int) -> int:
    if not isinstance(n, int):
        raise TypeError("n должно быть целым числом")
    if n < 0:
        raise ValueError("Факториал определён только для неотрицательных чисел")
    return 1 if n == 0 else n * factorial_recursive(n - 1)
```

Пример использования:
```python
print(factorial(5))  # 120
print(factorial(0))  # 1
```
