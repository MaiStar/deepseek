Вот пример функции на Python для вычисления факториала с использованием итеративного подхода (рекомендуется для больших чисел из-за отсутствия рекурсивного стека), а также рекурсивная версия для наглядности. Обе функции корректно обрабатывают отрицательные числа (выбрасывают исключение) и возвращают целое число.

```python
def factorial_iterative(n: int) -> int:
    """
    Вычисляет факториал числа n итеративно.
    Для n < 0 выбрасывает ValueError.
    """
    if n < 0:
        raise ValueError("Факториал определён только для неотрицательных чисел")
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

def factorial_recursive(n: int) -> int:
    """
    Вычисляет факториал числа n рекурсивно.
    Для n < 0 выбрасывает ValueError.
    """
    if n < 0:
        raise ValueError("Факториал определён только для неотрицательных чисел")
    if n <= 1:
        return 1
    return n * factorial_recursive(n - 1)

# Пример использования:
print(factorial_iterative(5))    # 120
print(factorial_recursive(5))    # 120
```

**Примечания**:
- Итеративный подход эффективнее по памяти и не ограничен глубиной рекурсии.
- Функция `factorial` из стандартной библиотеки `math` уже реализована и оптимизирована, но задание предполагает написание собственной.
