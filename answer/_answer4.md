## Есть несколько способов обойти это ограничение:

### 1️⃣ **OCR-сервисы** (извлечение текста из фото)
Если на фото есть текст, вы можете:
- Использовать бесплатные OCR-сервисы (например, OnlineOCR.net)
- Получить текст и передать его мне

### 2️⃣ **Гибридный подход** (для VS Code)
Вы можете написать скрипт, который:
1. **Использует API распознавания** (например, Google Vision API или Tesseract.js)
2. **Передаёт результат мне** для анализа

```python
# Пример: OpenCV + Tesseract для распознавания
import pytesseract
from PIL import Image
import requests

def analyze_photo(path):
    # 1️⃣ Распознаём текст на фото
    img = Image.open(path)
    text = pytesseract.image_to_string(img, lang='rus+eng')
    
    # 2️⃣ Отправляем текст мне
    response = requests.post(
        'https://api.deepseek.com/v1/chat/completions',
        headers={'Authorization': 'Bearer YOUR_API_KEY'},
        json={
            'model': 'deepseek-chat',
            'messages': [
                {'role': 'user', 'content': f'Анализирую фото. Текст с фото: {text}. Определи ТН ВЭД и ОКПД для товара.'}
            ]
        }
    )
    return response.json()

# Использование
result = analyze_photo('foto_tovara.jpg')
print(result)
```
